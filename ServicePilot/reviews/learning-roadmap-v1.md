## 面试开场参考

我以 GitHub 上的 OpenAI Agents SDK 航空客服示例为起点，先搭建 Python 运行环境、接入 DeepSeek，再沿着行李问答理解 Agent 分流、工具调用和回答生成的流程。随后，我围绕模拟电商售后明确需求和验收目标，在 Codex 协作下推进订单与政策查询、多轮会话、异常处理和真实案例验证，进一步做成 Streamlit 中文网页并部署上线。最后根据实际使用反馈，持续完善执行事件、源码展示、手机适配和页面层次，把示例逐步推进成可体验、可检查、可展示的作品。
