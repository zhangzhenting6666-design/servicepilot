## 流程与结构

输入 → OrderSession → Triage → FAQ或Order → lookup_faq/query_order → 本地模拟数据 → 根据本次结果回答。

Agent配置说明职责与工具，模型决定交接/调用，SDK的Runner执行并继续运行。DeepSeek负责生成与决策，本地工具提供事实，页面只显示后台返回值，不匹配完整问题后输出固定答案。

```text
ServicePilot/
  app.py                       中文聊天、重置、加载/错误、真实事件
  servicepilot/
    agent_config.py            Triage/FAQ/Order职责与工具绑定
    order_data.py / faq_data.py 可替换数据源与JSON读取
    order_tools.py / faq_tools.py 参数校验与结构化结果
    session.py                 SDK执行、历史与真实生命周期事件
    model_config.py            CLI/Web共用DeepSeek配置
    web_runtime.py             页面隔离、稳定异步循环、请求归属
    evidence_io.py             原子写入及Windows文件锁有界重试
  data/                        orders.json / policies.json
  evaluations/cases-v1.json     固定15开发/10留出清单
  scripts/                     启动、评测、离线检查与报告入口
  tests/                       离线工具/SDK/页面/会话/保存检查
  artifacts/                   原始运行、失败/修复、复核与截图
  docs/                        PRD、看板、报告、演示与贡献材料
```

航空参照与许可在上级openai-agents-python-main/examples和LICENSE。电商业务不导入航空Agent定义；密钥隐藏输入复用保留的航空启动助手。SDK从已安装发行包加载，未重写SDK。

## 本机启动与停止

已验证：Windows、Python3.13.16、openai-agents0.23.1、openai3.28.0、Streamlit1.65.0。实际解释器是上级openai-agents-python-main/.venv/Scripts/python.exe；ServicePilot/.venv是另一套旧环境，不是当前启动器使用的环境。

已有环境无需重装。双击本目录**启动聊天页面.cmd**，或从包含ServicePilot的工作区根目录运行：

```powershell
& '.\openai-agents-python-main\.venv\Scripts\python.exe' -X utf8 '.\ServicePilot\scripts\run_web.py'
```

仅在新启动终端的**DeepSeek API key:**提示后Ctrl+V隐藏粘贴并回车，不输入聊天、浏览器、PowerShell命令行或源码。密钥仅留进程内存，正文与记录脱敏，不保存请求头或原始服务异常。打开**http://127.0.0.1:8501**，只绑定本机，启动窗口保持运行。

停止：在启动窗口按Ctrl+C；批处理若询问是否终止，确认后关闭窗口。更新代码后须停止并重启服务，单纯刷新不能保证后台模块更新。端口占用时核对本项目进程，不结束无关Python；也可加--port 8502并访问8502。

CLI连续聊天：双击**启动订单客服.cmd**，或：

```powershell
& '.\openai-agents-python-main\.venv\Scripts\python.exe' -X utf8 '.\ServicePilot\scripts\run_order_customer_service.py' --fresh-key
```

CLI输入exit退出，每次启动新建会话。航空参照入口为**启动航空客服.cmd**，用途与电商产品分开，详见[启动与恢复](docs/基线与启动说明.md)。

## 已知限制

- 本地非流式；处理中禁用输入/新会话，不支持同时写下一条草稿、取消请求或自动重试模型。
- 新会话重建上下文，刷新会创建新页面会话；没有跨设备/重启恢复聊天，日志保留不等于聊天可恢复。
- 示例按钮仅填入草稿，发送后调用后台；未专门实现历史上翻保位/新消息提醒，长会话、其他设备与跨平台未完整验收。
- 中文正常发送已观察；**输入法候选框期间Enter仍待确认**，不记通过或失败。
- 缺失数据不能推算签收、到货、运费、到账时间或当前退货资格，没有真实业务执行或人工接入。
- 故障实测使用测试源；网络连接失败、空答复、重试等另有离线覆盖，不能都算真实外部故障测试。
