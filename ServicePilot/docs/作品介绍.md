# ServicePilot 作品介绍

2026-10-15更新。用于作品集的事实草稿，结合[个人贡献说明](个人贡献说明.md)确认个人表述。公开应用：[ServicePilot](https://servicepilot-c74sbjqk5s8ppt6tbmwltm.streamlit.app/)。

## 简短介绍

ServicePilot 是基于 OpenAI Agents SDK 航空示例、借助 Codex 改造的模拟电商售后 Demo。使用 DeepSeek，将中文问题分流给订单或政策客服，以参数化工具查询模拟数据，支持多轮补充、新会话重置和真实执行事件展示。浅色工作台的客服体验、架构总览和图文项目介绍已公开部署。历史固定样本最终开发15/15、留出第2轮重测10/10；首轮保存中断与修复记录保留。云端另完成5项关键场景验证，没有真实退款、工单、人工接入或登录。

## 作品集说明

目标是展示从需求、业务边界到工具链路和案例验收的完整过程。页面让用户查看模型实际调用了什么工具、输入了什么参数、查到了什么事实；缺编号先追问，无数据时说明不足，不能推算未提供的日期或承诺审核通过。

本人参与需求审阅、范围与验收确认、本机运行配合、页面反馈和流程学习；代码、验证和交付文档由 Codex 协助完成，复用官方SDK。固定小样本评测不是外部盲评或整体准确率保证。演示脚本和真实截图已准备，**视频未录制**；中文输入法组合态、云端全套25条、运行环境日志独立核对及长期稳定性验证仍待完成。云端5项验证与历史25条结果分别记录，不能合并为云端25条全部通过。
