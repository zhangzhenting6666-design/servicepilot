## 策略与现状

目标是模拟电商售后应用。航空示例用来学习 Agent、工具和交接，再逐步改造现有业务代码；无需重写 Agents SDK，也无需先构建完整前后端和数据库。

DeepSeek 环境与航空流程已真实运行通过：行李问答、选座意图转交、Wi-Fi 未查到资料，共 3 轮、12 次模型请求。当前示例做过 DeepSeek 兼容适配，不称为完全未修改的官方原版。官方业务路径仍可作为学习依据。

2026-10-13 已在工作区建立本地 Git，保留完整可恢复的航空基线与最小示例依赖；标签 airline-baseline-2026-10-13，功能分支 feature/order-query。独立订单入口已接入产品业务模块，C02 与一种改写通过真实 DeepSeek 验收。已有基线与依赖整理不需重复；不要覆盖已有工作或为每个聊天复制项目。

## 日常节奏

读任务看板 → 确认一个任务和验收 → 理解或实现 → 做对应检查 → 记录证据、问题和下一步。
