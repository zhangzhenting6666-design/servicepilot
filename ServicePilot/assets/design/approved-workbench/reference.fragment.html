项目介绍

让售后助手的行为可检查。

基于 OpenAI Agents SDK 与 DeepSeek，在 Codex 协助下构建的模拟售后 Demo。

可体验的能力

订单与政策查询、多轮补充、角色交接、新会话和事件查看。

验证与边界

固定样本开发15/15、留出重测10/10；首轮中断记录保留。无真实退款或人工接入。

推荐方向：产品体验与执行过程同时可见样例内容 · 不发 API 请求
